# FlowMind 开发实录（大纲）

> 定位：面向学习者的**开发实录**，以 FlowMind 的九阶梯迭代为主线，第一人称还原一个 AI 工作流平台从零到上线的完整过程——每个阶梯一章，讲「为什么这么做、怎么做、踩了什么坑」。不是「你应该」，是「我们做了」。
> 读者画像：有 Java/Spring Boot 和 Vue 基础，想了解 LLM 应用开发、消息队列、工程化实践的学习者。
> 配套：每章末有「面试深挖」小节；全书末有「真实 bug 故事集」。

## 第 0 章 起点：为什么做这个项目

- 项目定位：对标 Dify/Coze 的迷你工作流平台，一句话价值主张
- 技术选型思路：为什么是 Java 而不是 Python（求职定位）、为什么不用 LangChain4j（版本矩阵与锁契约的教训）
- 阶梯式交付方法论：每阶都是完整可演示的里程碑

## 第 1 章 MVP：跑通「表单配置 → 执行 → 流式输出」

- Spring Boot 3 分层架构起步；四类节点（输入/LLM/条件/HTTP）的表单式配置
- 顺序执行引擎 v1：拓扑校验 + 条件路由
- SSE 流式输出：为什么不用 EventSource（Authorization 头）、nginx proxy_buffering
- Redis Lua 原子限流；JWT 认证
- 面试深挖：Lua 脚本为什么原子、SSE 与 WebSocket 选型

## 第 2 章 可视化编排：Vue Flow 拖拽画布

- DAG 画布三栏布局；条件分支多出口连线
- 图合法性校验：环检测、孤立节点、重复边
- 画布与表单共用同一份图数据模型（graphModel 契约）

## 第 3 章 并行执行引擎（核心章）

- Kahn 拓扑排序 + 动态就绪队列 + CompletionService 线程池
- 无依赖节点并发执行；条件分支运行时路由
- 汇聚节点惰性跳过判定：为什么不能「上游跳过就跳过」（多父汇聚语义）
- fail-fast 失败传播；48 个单元测试如何覆盖边界语义
- 面试深挖：就绪队列入队判定、线程池参数、竞态处理

## 第 4 章 Function Calling：让 LLM 调用工具

- DeepSeek 流式 tool_calls 分片解析（按 index 拼装）
- 多轮代理循环：工具调用 → 结果回填 → 自动再问
- 轮数截断、工具失败回填不 fail 节点、多轮 usage 求和计费
- 面试深挖：中间轮为什么不上屏（仅最终轮缓冲重放）

## 第 5 章 RAG：给工作流装上知识库

- 文档切分（500 字 chunk + 50 字重叠，参数怎么定）
- bge-m3 Embedding（1024 维）与 Chroma 向量库（余弦相似度、score 换算）
- 检索 Top-K 注入生成，回答附带引用来源
- 面试深挖：为什么不用 FAISS/Milvus、为什么弃用 LangChain4j 的 RAG 封装

## 第 6 章 可靠性：RabbitMQ 异步执行

- 为什么从线程池升级到消息队列（重启丢任务事故：execution 107 卡死案例）
- 发布确认 + 手动 ack + 接力重试（x-retry-count header、republish 而非 requeue）
- 死信队列 DLX/DLQ；Redis 分布式锁（SET NX EX + Lua check-and-del）
- 启动恢复：startedAt < JVM 启动时间的时间窗口判定
- 面试深挖：requeue 与 republish 的区别、消息幂等、prefetch=1 的取舍

## 第 7 章 定时触发：Quartz 接入

- 内存模式 + 动态注册/删除；ApplicationReadyEvent 恢复
- MISFIRE_INSTRUCTION_FIRE_NOW 语义；触发复用 submit(triggerType)
- 与 MQ 的衔接：到点触发即入队

## 第 8 章 产品化：把工作流发布为 HTTP API

- API Key 一次性展示（SecureRandom 32B hex）；公开端点 /api/public/run/{key}
- 双限流（key 10/min + owner 10/min）与跨 key 越权防护
- 在线调试器：动态输入表单 + 轮询
- 面试深挖：API Key 为什么只展示一次（哈希存储）

## 第 9 章 数据闭环：统计仪表盘

- SQL 聚合：CASE WHEN 状态计数、DATE_FORMAT 30 天补零、来源分布
- 组合索引 idx_user_started 的由来
- ECharts 深色主题；执行数/tokens 双指标切换（为什么不用双 Y 轴）

## 第 10 章 部署与性能

- 阿里云 ECS + nginx 路径前缀双应用共存 + systemd
- 前端性能：gzip（1.1MB→438KB）+ immutable 缓存，首屏 20s→1s
- JMeter 压测实践：10 并发 p95 240ms、限流验证（12 连发 9 过 3 拒）
- 环境变量管理：PUBLIC_PATH_PREFIX 与 MSYS 路径转换坑

## 第 11 章 契约驱动与多 AI 协作（方法论章）

- API 契约作为唯一真相：契约先行、机器验收（contract_check.py 56+ 项）
- 领土隔离、任务卡、进度同步：如何组织多 AI 协作开发
- 生产构建铁律的由来（mock 模式事故）

## 第 12 章 真实 bug 故事集

1. 线上 SSE 全挂：三根因排查（硬编码路径 / 异常处理器崩溃 / 前端降级提示）
2. 鉴权失败返回空 500：Accept: text/event-stream 内容协商 406 的深层原因
3. 工作流永久 409：jstack 证明任务不在 JVM → 重启窗口丢任务 → 启动恢复机制
- 每个故事按「现象 → 排查 → 根因 → 修复 → 教训」五段式
