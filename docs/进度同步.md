## 协作规则（每次开工都提醒 agent）

1. **领土隔离**：GLM 只碰 backend/（除 engine/ 包），WorkBuddy 只碰 frontend/，Claude 维护 docs/ 和 engine/ 包
2. **git 独占**：只有统筹（Claude）运行 git 命令，两个编码 agent 与人都不要操作 git（改动由统筹验收后统一提交）
3. **契约神圣**：接口以 docs/API契约.md 为准，谁要改先找统筹
4. **端口**：后端 8080、前端 5173，不要占用
5. **环境**：MySQL 库名 flowmind；DeepSeek Key 在环境变量；不要硬编码密钥
6. **数据库**：schema 以统筹给的 SQL 为准，agent 不擅自改表结构；改表先提统筹
