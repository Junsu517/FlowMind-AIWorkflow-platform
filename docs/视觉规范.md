# FlowMind 视觉规范 v1（给 WorkBuddy 的 UI 打磨标准）

> 目标：现在的页面"中规中矩"，需要升级为"一眼记住"的 AI 产品质感。
> 本轮只打磨现有页面（登录/注册/列表），阶梯 2 的画布编辑器必须延续本规范。

## 设计语言

**关键词**：深色科技感 + 玻璃拟态 + 霓虹渐变点缀。定位是 AI 工作流产品（参考 Linear / Vercel / Dify 的质感）。

## 设计令牌（CSS 变量，统一放 global.css）

```css
:root {
  /* 深色主题（默认即深色，不做浅色切换） */
  --bg-base: #0b0e14;          /* 页面底色，近黑带一点蓝 */
  --bg-elevated: #11151f;      /* 卡片底 */
  --bg-glass: rgba(255,255,255,0.04);  /* 玻璃卡片 */
  --border-glass: rgba(255,255,255,0.08);
  --text-primary: #e6e9f0;
  --text-secondary: #8b93a7;
  --accent-1: #6366f1;         /* 主色：靛蓝 */
  --accent-2: #22d3ee;         /* 辅色：青 */
  --gradient-brand: linear-gradient(135deg, #6366f1 0%, #22d3ee 100%);
  --radius-lg: 16px;
  --radius-md: 12px;
  --shadow-glow: 0 0 40px rgba(99,102,241,0.25);
}
```

## 组件规则

1. **卡片**：`backdrop-filter: blur(20px)` + `background: var(--bg-glass)` + 1px 半透明描边 + 大圆角（16px）。悬停时描边变亮、轻微上浮（translateY(-2px) + 过渡 0.2s）
2. **主按钮**：品牌渐变底（indigo→cyan）+ 白字 + 悬停时发光（shadow-glow）；次按钮用玻璃底 + 描边
3. **标题字**：不用纯白，用 text-primary；描述字一律 text-secondary
4. **页面氛围**：背景加两个大号模糊渐变光斑（fixed 定位、radial-gradient、opacity 0.15 左右，一个靛蓝在左上、一个青在右下），登录页光斑更大更明显
5. **登录/注册页**：居中玻璃卡片（宽 ~420px），左侧或上方放品牌区——Logo 用渐变方块 + "FlowMind" 字样 + 一句 slogan（如"编排你的 AI 工作流"）；卡片内输入框统一深色、圆角、聚焦时描边变主色
6. **工作流列表页**：顶栏（玻璃、sticky）+ 页面标题 + "新建工作流"主按钮；卡片网格（2-3 列自适应）；每张卡片：名称、描述（两行截断）、底部元信息行（节点数徽章 + 更新时间）+ 悬停浮现操作按钮（编辑/删除）；**空状态要有设计**：渐变图标 + 引导文案 + 按钮
7. **动效克制**：路由切换淡入（0.2s）、卡片悬停过渡、弹窗弹性缩放。不要夸张动画
8. **细节**：数字/徽章用等宽感字体或加字距；删除确认弹窗用 danger 色按钮；全站无 emoji 做图标（用 Element Plus Icons）
