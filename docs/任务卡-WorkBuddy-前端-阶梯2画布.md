> 把本任务卡 + docs/API契约.md + docs/视觉规范.md + docs/进度同步.md 一起粘贴给你。
> 目标：把表单式编辑器**升级为拖拽画布**。这是项目的视觉名片，做精致。

## 你的领土

- 允许：frontend/ 目录下所有文件
- 禁止：改 backend/、docs/；运行 git；私自改契约

## 核心原则：换皮不换骨

- 数据模型完全不变：nodes/edges 数组、`PUT/GET /api/workflows/{id}/graph` 接口、你已有的 `graphModel.js`、`DebugPanel.vue` 全部沿用
- 本次只替换**编辑交互层**：表单卡片列表 → 画布拖拽连线
- DebugPanel 的 SSE 逻辑不动，只挪位置（画布页面底部）

## 任务清单

### A. 画布编辑器（WorkflowEdit.vue 重构）

1. 安装 `@vue-flow/core`（还有 @vue-flow/background、@vue-flow/controls 两个配套包）
2. 三栏布局：
   - **左侧节点面板**：4 类节点卡片（输入/LLM/条件/HTTP），拖拽到画布即创建（Vue Flow 的 drag-and-drop API，dragover 时高亮画布）
   - **中间画布**：节点可拖动、缩放（滚轮）、框选；背景点阵（延续视觉规范深色）
   - **右侧配置面板**：点选节点后显示对应类型配置表单（复用/迁移 NodeCard.vue 里的表单逻辑）
3. **自定义节点组件**（4 个）：深色玻璃卡片风格，显示：节点类型图标 + 名称 + 运行状态点（调试时高亮）；条件节点特殊：右侧出多个 handle（每个分支规则一个 + default），handle 旁标分支名
4. 连线：`sourceHandle` 规则与现有 edges 一致（条件节点分支边带 handle 名）；拖拽连线时显示虚线预览
5. 模板渲染细节：prompt/http 参数输入框保留「插入引用」下拉，引用列表从上游节点动态收集（nodeKey + output_key 字段）
6. llm 配置表单**新增**（契约已更新）：tools 多选下拉（数据来自 GET /api/tools）+ max_tool_rounds 数字输入（默认 3，可为空）
7. 保存：画布序列化 → 现有 graphModel → `PUT /graph`；加载反向
8. 本地校验 + 后端 INVALID_GRAPH message 弹窗逻辑沿用
9. 模板按钮（天气助手/条件分支）保留，一键生成后画布上直接呈现节点和连线

### B. 调试面板整合

- DebugPanel 移到画布页底部（可折叠抽屉）
- 运行中：画布上对应节点卡片状态点实时变色（灰/蓝/绿/红/橙，沿用现有颜色语义），LLM 节点 token 打字机继续在面板展示

### C. 视觉要求（这是名片，务必精致）

- 全程《视觉规范》：深色 #0b0e14、玻璃卡片、渐变主色 #6366f1→#22d3ee
- 节点选中态：渐变描边 + 发光；连线选中态：主色高亮
- 空画布状态：居中引导（图标 + "从左侧拖入节点开始搭建"）
- 最小化动画：节点拖入时轻微缩放浮现，连线 0.15s 淡入
